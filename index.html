How it works

One dashboard. Every signal. Every Monday.

The hub is a single browser-openable HTML page. No login for the public version, no database, no dependencies. Behind it, a scheduled task refreshes every marker block from primary sources every Monday at 9 am Central.

// 01

Portal-first sourcing

Every RFP, PDUFA date and congress checkpoint is verified against the funder or society's own page. Nothing inferred. No named individuals.

// 02

Weekly refresh

Every Monday 9 am CDT: signals, supporters, competitive intel, trial snapshot, congress calendar, PDUFA calendar, therapeutic-area radar, RFP directory.

// 03

Signal → checkpoint

Congress dates back-solve to 9-, 6- and 3-month checkpoints: satellite proposal → application → travel + supporter follow-up.

// 04

Gap finder

Cross-references competitor education across Medscape, PeerView, Clinical Care Options, ACHL and society providers to locate white space.

// 05

Trial snapshot

ClinicalTrials.gov API pull surfaces phase 3 readouts against the tracked supporter cohort — 12–18 months before enduring lead-time.

// 06

Provenance strip

Every block shows its last-verified date. No date is ever advanced without a re-verified source, so a stale block is visible.
